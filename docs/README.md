# CodeYF 编程智能体文档集

本文档集定义一个不依赖 Agent 框架、完全在本地执行工具的编程智能体。文档以首个可交付版本（MVP）为基线，同时保留后续演进空间。

3. [接口说明书](./03-interfaces.md)：CLI、配置、模型适配器、工具、事件与持久化接口契约。

## 基线技术假设

- 交付形态：本地命令行程序（CLI）。
- 推荐实现语言：Python 3.11 或更高版本。
- 模型接入：OpenAI 兼容 Chat Completions API；适配层允许扩展其他厂商原生 API。
- 智能体模式：单智能体、顺序工具调用、ReAct 风格闭环。
- 工具执行：文件读写、目录检索与命令执行全部在用户本机完成。
- 工作区边界：默认只允许读写启动命令指定的工作区目录。
- 文档中的 `MUST`、`SHOULD`、`MAY` 分别表示必须、建议和可选。

## 建议实现里程碑

| 里程碑 | 范围 | 完成标志 |
|---|---|---|
| M1：可用闭环 | 模型调用、历史管理、5 个核心工具、循环控制 | 能独立完成一个小型跨文件修改任务 |
| M2：可靠性 | 审批、安全边界、事件日志、重试、上下文压缩 | 失败可诊断，危险操作受控，长任务不轻易溢出上下文 |
| M3：工程化 | 会话恢复、插件式工具注册、评测集、更多模型适配器 | 可重复评测，可扩展而不改动核心循环 |
